## 2026-11-06 15:00–17:18 并发限流（429）

- 原因：`run_parallel --workers 3` 同时运行 3 个 `run_trials` 进程，触发智谱账户级速率限制。
- 现象：`OpenAIRateLimitError: Error code: 429`，单条约 6 秒即失败；影响 16 条 S2 运行记录。
- 处置：删除这 16 条记录，改为 `--workers 1` 串行重跑；重跑后的记录进入最终 66 条有效数据。
- 统计口径：这 16 次尝试**不计入** FDR/OMR/HPR 等质量指标；它们也不属于 Agent 规划失败。
- 局限：原始 JSON 已被删除，本文件只保留数量、原因与时间范围；后续版本应在删除前归档到 `evaluation/trials/<run>/excluded/`。
- 代码改进：`run_trials` 已把 `RateLimit/429` 归类为 `infra`，并加入 trial 级 60/120/180 秒退避重试。
