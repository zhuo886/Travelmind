## 4. 不可写与边界

- 不可写“线上路距核验 P50 降低 X 倍”：本轮是调度仿真，不是线上观测。
- 串行臂仍是同一节点代码，只是执行器宽度为 1；不存在“另写一个慢实现”的对照偏差。
- 若 N < 8，加速比上限是 N；报告请同时给出 N 与并发度，避免用大 N 掩盖小场景收益。
